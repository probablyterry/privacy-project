# privacy-project
this a hobby project of mine that I started when I realized that web activity is frequently being monitored. Run one of these scripts while you're hanging out. Determine the web traffic you crawl. Pick porn that makes your "admin" uncomfortable, or bore them to death.
browser_traff_gen_random_dwell.py caps crawl time and generates browser based traffic with randomized dwell time between 5 seconds and 6 minutes.

traffic_crawler.py is simple and generates http traffic and does not interact with media or javascript. it can wander off site, and there is no timelimit. 

I hope you find one of these helpful. I'll be continuing to work on these and a few other projects. Ill publish whenever I'm able. any question or, if you see something that needs to be improved, Reach out!! I'm still learning.
